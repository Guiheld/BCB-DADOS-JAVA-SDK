## Como relatar uma vulnerabilidade

Por favor, **não** abra uma _issue_ pública para vulnerabilidades de segurança.

Use o canal privado de **GitHub Security Advisories** do repositório:
<https://github.com/Guiheld/BCB-DADOS-JAVA-SDK/security/advisories/new>

Descreva o problema, o impacto e, se possível, os passos para reproduzir. O relato será analisado e
respondido com a maior brevidade possível.
